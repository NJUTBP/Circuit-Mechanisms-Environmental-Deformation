# Model and analysis code

- [`run/`](run/README.md): model simulation, experiment configurations, and parameter sweeps.
- [`analysis/`](analysis/README.md): network metrics, statistics, and transfer-entropy analysis.

Install dependencies from the repository root:

```bash
python -m pip install -r requirements-analysis.txt
```

Figure scripts and data are in [`../Figs_CTP/`](../Figs_CTP/README.md).
