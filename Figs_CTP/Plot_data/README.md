# Figure data

Each `main_figure_N/` or `supp_figure_N/` directory contains the inputs for the
corresponding `../Plot_code/plot_*.py` script.

- CSV: per-network values, group curves, and statistics.
- NPZ: rate-map arrays.
- JSON: geometry and summary parameters.
- PDF: Main Figure 1 diagram.

See the [figure data index](../../docs/DATA_INDEX.md) for file locations and
[DATA_FILES.csv](../../docs/DATA_FILES.csv) for CSV fields, row counts, and array
shapes. Columns such as `_cm`, `_m`, and `_bits_per_spike` indicate units.
